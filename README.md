# Flask CRUD - Practica UPQ

Aplicacion web desarrollada con Python, Flask y MySQL.

## Funcionalidades
- Registrar contactos
- Consultar contactos
- Editar contactos
- Eliminar contactos

## Ejecucion
1. Configurar MySQL y crear la tabla con sql/db.sql.
2. Crear el archivo .env a partir de .env.example.
3. Instalar dependencias con pip install -r requirements.txt.
4. Ejecutar python app/main.py.
5. Abrir http://localhost:8080.

Practica de Manejo Masivo de Datos.
